# MysteryBox - Python Mini Project

## About
MysteryBox is a Python mini project developed to demonstrate Python programming concepts through an interactive application.

## Features
- Interactive graphical user interface.
- Organized code using separate folders.
- Python-based application logic.
- Data management using project files.

## Technologies Used
- Python
- Tkinter (if used in the project)

## Project Structure
- `main.py` - Main entry point of the application.
- `gui/` - Graphical user interface components.
- `logic/` - Application logic.
- `data/` - Project data files.

## Purpose
Created as a Python mini project to practice programming and application development.
